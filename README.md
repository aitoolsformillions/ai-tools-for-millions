# AI Tools for Millions — MVP Starter

Production direction: Next.js App Router + TypeScript + Tailwind CSS + Supabase.

## Run locally
1. Install Node.js LTS.
2. In Terminal, enter this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Supabase
- Create a Supabase project.
- Copy `.env.example` to `.env.local` and add project values.
- Run `database/001_initial_schema.sql` in the Supabase SQL Editor.
- Never expose `SUPABASE_SECRET_KEY` in browser/client code.

## Included routes
- `/` homepage
- `/tools` Tool Explorer
- `/tools/[slug]` Tool details
- `/dashboard` dashboard shell
